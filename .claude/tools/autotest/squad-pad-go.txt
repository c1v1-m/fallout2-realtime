# SQUAD COMMAND BY THE PAD: GO, out of a fight, and FOLLOW ending it (2026-11-12, his design "A", „můžu mu i říkat
# kam má jít?“). Vic runs his own party script (DCVic.int, scripts.lst line 50) -- the follow that walks him back to the
# dude whenever he is more than 9 tiles off. LT + A opens the mode, the right stick takes the cursor 8 tiles left of
# the dude, A = GO (who = All, Vic alone): he walks there and holds it. The dude walks off to the right: Vic's script
# would fetch him, but the post holds (GVAR_PARTY_NO_FOLLOW around his heartbeat, squad-follow-held). Then LT + A and
# D-pad Down = FOLLOW: the post ends and he comes.
#   node ../fallout1-ce/.claude/tools/autotest/run.js .claude/tools/autotest/squad-pad-go.txt 1 --exe build/Release/fallout2-ce.exe
name squad-pad-go
map DESERT1.MAP
seed 1
duration 17
dude tile 20100 rot 2
dude hp 400
dude armor 2

spawn 16777278 19904 rot 5 wield 8 item 29 3 party script 50

# LT + A: the mode, the cursor 3 tiles ahead (474,226)
axis 500 LT 32767
tap 700 A
axis 1000 LT -32768
# the cursor onto free ground 8 tiles left of the dude (474,226 -> 234,238)
axis 1300 RX -26181
axis 1300 RY 1309
axis 1809 RX 0
axis 1809 RY 0
# A: GO
tap 2400 A
# the dude walks off to the right for 3 s (well past the 9 tiles at which Vic's script fetches him)
axis 5500 LX 32767
axis 8500 LX 0
# LT + A, D-pad Down: FOLLOW -- the post ends
axis 10000 LT 32767
tap 10200 A
axis 10500 LT -32768
tap 10900 DOWN
note 16500 end

# the checks (run.js)
expect \[FLOW/autotest\] script pid=16777278 line=50 rc=0
expect \[FLOW/autotest\] party-add id=18062 pid=16777278 rc=0
expect \[INPUT/squad-a\] kind=ground order=go obj=-1 tile=\d+ who=all ok=1
expect \[ACTION/squad-order\] order=go target=- companions=1 skipped=0 why=ok speaker=18062 t=[\d.]+ who=all tile=\d+
expect \[FLOW/squad-post\] set id=18062 pid=16777278 tile=\d+
expect \[FLOW/squad-post\] arrive id=18062 pid=16777278
expect \[FLOW/squad-follow-held\] id=18062 pid=16777278 heal=0 post=\d+
expect \[FLOW/squad-post\] kept id=18062 pid=16777278 tile=\d+ dude=\d+
expect \[INPUT/squad-dpad\] dir=down order=follow who=all ok=1
expect \[ACTION/squad-order\] order=follow target=- companions=1 skipped=0 why=ok speaker=18062 t=[\d.]+ who=all
expect \[FLOW/squad-post\] end id=18062 pid=16777278 tile=\d+ held=[\d.]+ why=follow
expect-count 2 \[INPUT/squad-mode\] close why=
expect-not \[ACTION/interact-(queue|do)\]
