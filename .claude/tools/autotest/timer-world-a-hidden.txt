# THE A MARK TELLS THE TRUTH (review 2026-11-15): the bomb's SET TIMER window, opened from the WORLD (the RB quick slot),
# marks A on DONE and hides the pointer after two seconds of rest. A pressed the button under a pointer that had
# moved since the open -- hidden or not -- so one push of the left stick left the pointer on CANCEL, two seconds hid
# it, and the A the window marks on DONE pressed an invisible CANCEL: the bomb not armed, the quick slot's AP spent
# all the same. Now A follows the pointer only while its arrow is on the screen; with no arrow showing, A is DONE.
# 1st window: one push right (the arrow on CANCEL), two seconds of rest (hidden), the D-pad to 1:30, A -- DONE, and
# the armed bomb goes down (in Fallout 2 the world's DONE puts it down, gamepad_ui.cc gpui_quick_use_item).
# 2nd window: up and down (the arrow onto PLACE, then CANCEL) and A at once -- the arrow is showing, so A presses
# CANCEL, the button it is on: the snap + A route is kept.
# Before the fix (the implementer's exe): the 1st window closed as CANCEL (value 90), nothing went down.
